# Demo account portraits

`manager.svg`, `rep_a.svg` and `rep_b.svg` are original flat illustrations drawn for the fictional demo
accounts (no real person is depicted). To use photo portraits instead, add `manager.jpg` (or `.png` /
`.webp`), `rep_a.jpg` and `rep_b.jpg` here: a photo is preferred over the illustration when present.
Use only images of people who do not exist (generated portraits) or with the subject's permission.
